# ฝ้ายพลิ้ว หน้าร้านตัวอย่าง (faiplio-storefront)

หน้าร้านเล็กๆ สำหรับ demo ของโปรเจกต์ CS Support RAG ข้อมูลทั้งหมดเป็นของสมมติ

## ไฟล์

- `index.html` หน้าเดียว มีแบนเนอร์ส่งของ รายการสินค้า สรุปตะกร้า และส่วนท้ายเว็บ
- `content/th.json` ข้อความทุกตัวที่แสดงบนหน้าเว็บอยู่ในไฟล์นี้ แก้ข้อความที่นี่ที่เดียว

## วิธีดู

เปิดผ่านเว็บเซิร์ฟเวอร์ในเครื่อง เพราะหน้าเว็บโหลด `content/th.json` ด้วย fetch:

```bash
npx -y serve .
```

แล้วเปิด URL ที่ขึ้นในเทอร์มินัล

## หมายเหตุ

repo นี้ใช้ทดสอบการแก้ข้อความอัตโนมัติ ข้อความในหน้าร้านอาจไม่ตรงกับนโยบายของร้านทั้งหมด
